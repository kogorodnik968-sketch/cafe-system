# REST-сервис системы кафе (Cafe System)
Данный проект представляет собой разработку базового REST-сервиса для управления продуктами кафе.
Сервис реализован с использованием фреймворка Spring Boot и демонстрирует принципы построения многослойной архитектуры, обработку HTTP-запросов и использование DTO для передачи данных.

# Архитектура приложения

Проект реализует классическую многослойную архитектуру, состоящую из трёх уровней:

## Controller Layer (Уровень контроллеров)
Принимает и обрабатывает HTTP-запросы

- Использует @GetMapping, @PostMapping, @PutMapping, @DeleteMapping

- Использует @PathVariable для извлечения параметров из URL

- Использует @RequestParam для параметров запроса

- Возвращает ответы в формате JSON

- Возвращает корректные HTTP-статусы

## Service Layer (Сервисный уровень)

- Содержит бизнес-логику приложения

- Выполняет поиск продуктов

- Выполняет фильтрацию по параметрам

- Реализует маппинг между сущностями и DTO

- Обрабатывает исключительные ситуации

## Repository Layer (Репозиторий)

- Обеспечивает доступ к данным

- Использует in-memory хранилище (List)

Хранит список продуктов внутри приложения

Предоставляет методы поиска и получения данных

# Модель данных

## Сущность Product (Продукт)
- id — уникальный идентификатор продукта

- name — название продукта

- price — цена продукта

- category — категория продукта

- available — доступность

## Data Transfer Object (DTO)
Для изоляции клиентской части от внутренней модели используется:
ProductDto — объект, который возвращается клиенту через API.

DTO позволяет:

- изолировать внутреннюю модель

- контролировать формат ответа

- соблюдать принципы чистой архитектуры

# Реализованные REST-endpoints

## Получить все продукты
GET/products

## Полуить продукт по названию
GET/products/{id}

## Полуить продукт по названию
GET/products? name=Coffee
